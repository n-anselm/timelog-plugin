## 0. Read this first

This plugin shows notes that have dates in their frontmatter on one continuous horizontal timeline. It is a private, single-user plugin — not published to the Obsidian community store.

**Trust order when documents disagree:**

1. `src/*.ts` and `src/styles.css` — the truth.
2. This file — verified notes and intent.
3. `README.md` — user-facing, and currently **stale** (it promises tags in popups and a "22 KB" bundle; neither is true).

**Never edit these by hand:**

- `main.js` — generated by esbuild from `src/main.ts`.
- `styles.css` (root) — copied from `src/styles.css`; Obsidian only loads the root copy.

**Git & verification:**

- The plugin directory is a git repo (`node_modules/` and `data.json` are gitignored; `main.js` and `styles.css` are tracked because the repo lives directly inside `.obsidian/plugins/obsidian-timeline/`).
- Do not create git commits unless the user explicitly asks you to.
- Do not leave backup copies of the plugin folder inside `.obsidian/plugins/` — Obsidian indexes plugins by `manifest.json` `"id"` (`obsidian-timeline`), so a backup folder inside `.obsidian/plugins/` will shadow this folder.

## 1. Current state (v1.1.0)

### Implemented and working (main view & embedded view unless noted)

- Read-only vault indexing from a configurable folder (default `Calendar`), subfolders optional, plus an optional **Global note filter** (`none` / `include` / `exclude`) with multi-condition rules.
- Start date from frontmatter (`date`, `startDate`, `start`) or a `YYYY-MM-DD` in the filename, with strict calendar validity checking (rejects impossible dates like `2026-02-31`).
- End date from frontmatter (`date-end`, `endDate`, `end`) for multi-day bars.
- Optional alias label mode (`useAliasAsLabel`, off by default): uses the first `aliases` / `alias` entry as the event title/label when enabled.
- Frontmatter `image` preview support: resolves wiki-links (`"[[image.jpeg]]"`), markdown links, vault paths, and URLs to a thumbnail in the hover popup, plus a `75vh` hover lightbox (`Esc` or mouse-out to close).
- **Condition-based Categories & Colors (Linear Calendar style):**
  - Each category has an expandable card in Settings with drag-to-reorder priority (first match wins), enable checkbox, colour picker + hex/CSS variable input, `matchMode` (`All (AND)` / `Any (OR)`), and a multi-condition builder.
  - Conditions support `Tags`, `Folder` (with `Subfolders` option), `File Name`, `File Basename`, `Path`, `Extension`, and any `Custom frontmatter property`, with operators `is`, `is not`, `contains`, `does not contain`, `starts with`, `ends with`, `matches date pattern` (`+ text`), `exists`, and `does not exist`.
  - Uncategorized notes are hidden by default (`showUncategorizedNotes: false`) so only notes matching at least one enabled category appear on the timeline. Legacy `cat.tag` configs migrate automatically via `normalizeCategoryConfig()`.
- Horizontal view as a tab (ribbon icon and command), plus a ```` ```timeline ```` code block embed with `MarkdownRenderChild` cleanup on unload.
- Single central axis (`4px` thick); `16px` dots for single-day events, scaled bars (`22/12/6px`) for ranges.
- Same-day point events spread horizontally across their day column (`(idx + 1) / (count + 1)`) and uncluster automatically at `≥ 30 px/day` into separate dots and alternating above/below stems.
- Persistent month + day ruler (`76px` tall) with viewport-virtualized day cells (`renderVisibleRulerDays`). At `< 30 px/day`, the days row fades out over `0.4s` in place without shifting the timeline stage. When zoomed out to where a year is `≤ 50%` of the viewport width, monthly dividers and monthly grid lines hide and the year label overflows cleanly (`is-year-block`).
- Single-layer CSS repeating gradients for axis day ticks (`.timeline-day-ticks-layer`, toggleable via `showDayTicks`) and weekly Monday grid lines (`.timeline-week-grid-layer`), avoiding thousands of DOM nodes.
- Adaptive labels: auto (hidden `< 30` → vertical `30–64` → horizontal `≥ 65`), or forced; configurable vertical label max height (`verticalLabelMaxHeight`, `60–360px`, default `120px`).
- Cluster bubbles (`24px`) for nearby events when zoomed out (`< 30 px/day`); clicking one zooms `max(30, round(px * 2.2))` centred on it.
- Configurable **Default view zoom (time span)** (`defaultViewSpan`, default `"6 months"`) and **Default view offset from today** (`defaultViewOffset`, default `"0"`).
- Today marker (line + badge) using configurable `todayMarkerColor`, optional grid lines (`showGrid`), optional axis day ticks (`showDayTicks`), and `autoScrollToToday`.
- Cursor-pinned wheel zoom (`1–140 px/day`), `requestAnimationFrame`-coalesced, with configurable **Zoom sensitivity** (`0.3–2.5`, default `1.0`) and velocity-based **Zoom acceleration** (`zoomAcceleration`, default `true`).
- Drag panning with heavy momentum, shift-wheel pan, trackpad horizontal pan.
- Keyboard shortcuts (scoped to `.obsidian-timeline-wrapper` focus so single-key defaults never hijack typing elsewhere in Obsidian, plus 11 commands registered in Obsidian's **Settings → Hotkeys**):
  - `Home`: Reset to default view (zoom & offset)
  - `0` / `Z`: Zoom out to fit all events
  - `←` / `→`: Pan left / right by 15% of viewport
  - `Shift + ←` / `Shift + →` or `PageUp` / `PageDown`: Jump `±1 Month`
  - `+` (`=`) / `-` (`_`): Zoom in / out
  - `L`: Cycle label display mode
  - `/`: Focus toolbar quick-search filter (`Esc` clears and returns focus)
  - Unassigned commands available in Hotkeys editor: `Center on today`, `Jump back 1 year`, `Jump forward 1 year`
- Toolbar: Today, `±Month`, `±Year` (with Lucide chevron icons), category filter pills, live `Filter events… (/)` search input, label mode dropdown, zoom slider and `±` buttons.
- Tooltip with `220ms` close delay (stays open while hovered), `0.12s` fade-in and fade-out, title, formatted dates/range, relative time, `color-mix()` category badge, optional image thumbnail + hover lightbox, and description.
- Live refresh on vault create/delete/rename and metadata change (`300 ms` trailing debounce). View-internal zoom/filter updates save quietly (`saveSettingsQuiet()`, `400 ms` debounce) without triggering a redundant vault rescan or double render.

### Known limitations (embedded view vs main view)

- Embedded ```` ```timeline ```` blocks clean up their tooltips and listeners on unload via `MarkdownRenderChild`, but they do not subscribe to live vault-change refreshes or persist toolbar filter/zoom changes back to `data.json`.
- Mobile touch/pinch handlers are not implemented (`manifest.json` has `isDesktopOnly: false`, interactions are mouse/trackpad/keyboard).

### Deferred features (intentional, not bugs)

- Double-clicking a day on the timeline/ruler to create a new event note on that date.
- Vertical timeline layout.
- Date-range filter.
- Touch / pinch support.
- Export (PNG, iCal).
- Multiple timeline panes with independent persisted state.
- Custom marker shapes (triangle, diamond, etc.).

## 3. Architecture and data flow

```
TimelinePlugin (main.ts)
├── TimelineView (ItemView, "obsidian-timeline-view")
│     └── HorizontalTimelineView (toolbar + persistent ruler + track content)
│           └── TimelineIndexer.getEvents(settings)
├── TimelineSettingTab
├── 12 Obsidian Commands (Settings → Hotkeys)
└── ```timeline``` code block (with MarkdownRenderChild cleanup)
      └── its own HorizontalTimelineView + TimelineIndexer
```

### Render & zoom flow

1. `render()` creates the persistent DOM once: `toolbarEl`, `scrollWrapperEl`, `timelineTrackEl`, `rulerEl` (`monthsRowEl` + `daysRowEl`), and `trackContentEl`.
2. On initial render (or when `defaultViewSpan` / `defaultViewOffset` changes in Settings), `pixelsPerDay` is computed from `defaultViewSpan` against the viewport width (`computeDefaultZoomPixelsPerDay()`), and scroll position is set from `defaultViewOffset` (`scrollToDefaultView()`).
3. `renderTrack()` empties only `trackContentEl` (never `rulerEl`), updates `monthsRowEl`, toggles `.is-collapsed` on `daysRowEl` for the uninterrupted `0.4s` fade, renders the visible day cells (`renderVisibleRulerDays`), and renders Today + axis + events.
4. `applyZoom()` updates `pixelsPerDay`, calls `onSettingsChange()` (`plugin.saveSettingsQuiet()` — a `400ms` debounced `saveData` with **no** `refreshOpenViews()`), and calls `renderTrack()` once. Wheel zoom events are coalesced to one `requestAnimationFrame` per frame.

## 5. Gotchas and lessons learned

| Area | Lesson |
|---|---|
| Duplicate plugin folders | Never leave backup folders inside `.obsidian/plugins/` — Obsidian keys plugins by `manifest.json` `"id"`, so a backup folder will overwrite the active plugin at load time. |
| Global CSS leaks | The installed **Linear Calendar** plugin defines global `.day-number { position: absolute; top: 3px; ... }`. Always keep `.timeline-day-tick .day-number` scoped with `position: static !important; top: auto !important;`. |
| Single-key hotkeys | Never pass unmodified single-character keys (like `l`, `z`, `0`) in `addCommand({ hotkeys })` — Obsidian's global `hotkeyManager` intercepts them across the whole app and blocks typing those letters. Keep single-key defaults on `.obsidian-timeline-wrapper`'s `keydown` listener and leave `addCommand` hotkeys `undefined` so users can optionally bind custom keys in Settings → Hotkeys. |
| Quiet saves on zoom | `HorizontalTimelineView` must use `saveSettingsQuiet()` (debounced `saveData` only), never `saveSettings()` (`refreshOpenViews()`), or every wheel notch will re-index the vault and render the timeline twice. |
| Persistent ruler | Keep `rulerEl` / `daysRowEl` persistent outside `trackContentEl` and fixed at `76px` height so the `0.4s` opacity fade on `.timeline-ruler-days` never shifts the timeline vertically or gets interrupted by wheel ticks. |
| CSS copy | Always `cp src/styles.css styles.css` after editing `src/styles.css` and check with `diff -q src/styles.css styles.css`. |

## 6. Decision log

- **UTC day arithmetic** — every date is `Date.UTC(y, m, d)` with strict calendar round-trip validation so DST cannot shift an event and impossible dates (`2026-02-31`) are rejected.
- **End date is inclusive** — `endTimestamp` adds 24 h so a range ending on the 15th covers the whole 15th.
- **One continuous `4px` axis** — single line with `16px` dots and `22/12/6px` bars.
- **Same-day event handling** — point events on the same date spread across their day column (`(idx + 1) / (count + 1)`) and uncluster automatically at `≥ 30 px/day` with alternating above/below stems.
- **30 px/day unified detail threshold** — ruler day cells, axis day ticks, auto labels, and same-day unclustering all activate together at `30 px/day`.
- **Year-half-screen zoom-out breakpoint** — once `365 * pixelsPerDay <= viewWidth * 0.5`, monthly dividers and monthly grid lines hide so only year blocks remain, with `overflow: visible` so year numbers never clip.
- **Virtualized ruler + CSS gradient layers** — day cells in the top ruler render only for the visible viewport (`±14` days buffer), while axis day ticks and weekly grid lines use single CSS `linear-gradient` layers.
- **Velocity-accelerated zoom** — slow wheel ticks step gently (~4.5%) for precision around breakpoints while fast wheel spins ramp up smoothly via `wheelZoomBurst`.
- **`color-mix()` for theme accents** — category badges and hover glows use `color-mix(in srgb, ...)` so `var(--interactive-accent)` works identically to hex colours.
